# Contributing

Thanks for helping improve this LeetCode Tree DSA repository.

## Adding a solution

1. Choose a tree problem and include its LeetCode number and title.
2. Put the solution in the most relevant topic folder under `src/`. If the folders do not exist yet, create the appropriate one.
3. Prefer a descriptive filename, for example `BinaryTreeLevelOrderTraversal.java`.
4. Add a short explanation of the approach and its time and space complexity. This can be in a comment or a small Markdown note.
5. Check edge cases such as an empty tree, a single node, skewed trees, and duplicate values where relevant.
6. Test the solution on the examples and any useful edge cases before submitting.

## Code style

- Use Java and readable names.
- Keep the algorithm focused on the problem.
- Avoid unrelated changes and copied solutions without understanding.
- State whether the code is a LeetCode submission (`class Solution`) or a standalone Java program.
- Do not claim a solution is tested unless it has actually been tested.

## Pull request checklist

- [ ] The problem number, title, and LeetCode link are included.
- [ ] The code follows the expected method signature.
- [ ] The approach and complexity are documented.
- [ ] Example cases and relevant edge cases were checked.
- [ ] No unrelated files or generated build output are included.

For a correction, describe the issue and provide an input that demonstrates it.
